# Competitive headroom is a joint progress-and-cost question

The current goal requires useful teacher headroom against strong, comparably optimized alternatives. An equal-round-cost coverage screen alone cannot prove that no cheaper learned replacement could be useful. Conversely, costs measured for one proposal policy cannot be assigned to a different one to manufacture headroom.

## Existing matched timing evidence

The completed original-tree-cost experiment measured these conditions on the same sixteen contexts, same A100 PCIe, and same actual verification machinery:

| Condition | Mean context-median complete-round time |
|---|---:|
| Original DFlash chain | 30.947 ms |
| Captured compact editor plus original | 31.534 ms |
| Ordinary tree, first guess fixed | 33.383 ms |
| Ordinary tree, first guess editable | 33.207 ms |

The learned editor added about 0.587 ms relative to the original round. The earlier 5–9% unoptimized editor overhead is not the latest execution result. Capturing the editor substantially reduced that overhead while preserving its tested outputs.

Using the measured per-response round-cost ratios, **if a new editor preserved these costs and matched the editable-first tree's progress**, its modeled saving would be about 5.03%. This is a counterfactual, not what the tested editor achieved. At these costs, a uniform progress ratio of about 0.9996 relative to that tree would meet the 5% modeled threshold. Changing proposals can also change verification/compaction cost, so the cost assumption must be checked after training.

The actual editor did not establish that result. The tree had greater useful progress, and its measured cost-per-position advantage over the editor was inconclusive on eight responses. Numerical disagreements remain recorded. Neither condition establishes a full-generation speedup or superiority over the newly released co-trained xPress model.

## What the 4.107% screen does and does not say

For one fixed context, let `c` be editor round cost divided by reference round cost, and `r` be editor progress divided by reference progress. Modeled latency saving is `1 - c/r`. The old 4.107% result assumed `c = 1` uniformly across responses. It did not measure both complete costs.

For that particular two-conditioned-score-tree policy, the reported progress distribution would require a uniform round-cost ratio no greater than about 0.99069 to model 5% savings: roughly 0.93% cheaper rounds than the ordinary reference. This is algebra from the rounded reported result, not evidence that such an implementation exists. Simply adding a student to otherwise unchanged ordinary-tree work does not provide that saving.

Crucially, the measured 31.534 ms editor uses a two-chain policy, **not** that two-conditioned-score-tree policy. Its cost cannot be substituted into the 4.107% calculation. The old teacher's separate two-chain-union comparison was adverse at equal cost (−0.581%); under a uniform cost-ratio model it would need approximately 5.55% cheaper rounds to reach 5% savings. Different panels, contexts and output numerics prohibit joining these figures into an observed speedup.

## Updated decision rule

Do not reject a compression target solely because its equal-cost progress estimate is under 5%. Require evidence that its achievable corrections and the replacement's complete cost could jointly beat the relevant alternatives. Equally, do not approve training by combining an optimistic teacher's coverage, an unrelated cheap policy's runtime and a weak comparator.

For any next fit, specify the exact proposals the student must produce and the actual inference policy. Use the latest captured student cost as a starting estimate, not a guarantee. Keep strong optimized drafting/refinement controls. The current stronger-backbone probe addresses correction value only; native complete costs remain a separate missing requirement if it is favorable.

This correction does not select another architecture, loss, tree optimization or training run. It keeps the user's second-pass compression question open on the appropriate economic terms.
